# 🐈‍⬛Black_Cat_API

**Library API** — это backend-приложение для управления книжной библиотекой: физической, электронной или гибридной.  
Проект реализует RESTful API с авторизацией, ролями пользователей и системой учёта книг, отзывов и выдач.

Основная цель — создать масштабируемую и логически цельную архитектуру, которая может быть использована как основа для:
- классической библиотечной системы (с библиотекарями и читательскими билетами),
- цифровых платформ вроде ЛитРес или Флибусты,
- небольших частных или локальных библиотек (семейных, корпоративных и пр.).

---

## 🔧 Базовая функциональность

- Регистрация и авторизация пользователей (JWT)
- Роли пользователей: читатель, автор, библиотекарь
- Управление книгами, жанрами и авторами
- Учёт выдачи книг (займы, возвраты)
- Оставление отзывов на книги
- Поддержка фильтрации и поиска

---

## 🧱 Стек

- Python / Django / Django REST Framework
- PostgreSQL
- JWT (SimpleJWT)
- Swagger/OpenAPI для автогенерации документации
- Docker (опционально)

---

## ⚙️ Расширяемость

Структура API позволяет добавить:
- Систему QR/NFC-пропусков
- Загрузку eBook-файлов (PDF, EPUB и пр.)
- Рекомендательную систему по предпочтениям
- Статистику и аналитику по пользователям и книгам
